The project is not an adaptation of an existing application. The interface, source comparison workflow, review ledger, CSS ghost illustration, and fictional prose examples were created for this project. Existing pretrained models and software libraries are credited in `THIRD_PARTY.md`.

Codex assisted with concept development, implementation, tests, actual execution, browser verification, and writing. The model actually used by the finished application is the pinned MiniLM model, not a closed assistant hidden behind sample output.
